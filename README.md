# Tetris-IO-MLX

A modern browser Tetris (Classic / Marathon / 40-Line Sprint), built as a
capability test for a local model (qwen3.8:27b-mlx) driving Claude Code.

## Run it

Open `index.html` directly in a browser. No build step, no server, no
install.

## Run the tests

```
node tests/run.js
```
